建议阅读顺序

  1. 先读 Unity 文档，弄清楚场景、对象、组件、生命周期和 Inspector 绑定。
  2. 再读 C# 文档，理解项目中高频出现的语法和工程写法。
  3. 最后读项目架构全景，把规则层、UI 层、AI 层和快照模拟串起来。
  4. 面试前重点看每篇文档里的“面试表达”和“本项目映射”。

当前定位

这组资料不是替代 Unity 官方手册，也不是 C# 完整教程。它只整理本项目真正用到、面试中高频会被追问、后续学习必须吃透的内容。官方知识以 Unity 文档和 Microsoft Learn 为出处；项目事实以本仓库代码和 Docs 为准。
